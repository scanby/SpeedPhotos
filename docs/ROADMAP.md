## Criterios de aceptación del MVP

- Una composición respeta las medidas físicas configuradas.
- Las fotos no se solapan.
- Los márgenes y separaciones se respetan.
- La vista previa coincide con el archivo exportado.
- Se puede seleccionar una impresora instalada y enviar el trabajo.
- Las funciones principales no requieren conexión a internet.
